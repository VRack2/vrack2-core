# vrack2-core

`vrack2-core` — фреймворк для создания и запуска сервисов на Node.js:
он предоставляет классы и правила, из которых сервис собирается и работает.
Схема простая: вы описываете сервис в JSON — какие устройства нужны и как
они соединены — а фреймворк берёт на себя механику: создаёт устройства,
проверяет настройки, соединяет порты, запускает, передаёт данные между
устройствами и сохраняет состояние и метрики.

Устройства — обычные JS-классы. Сервис — это список устройств и соединений
в файле `service.json`:

```json
{
  "devices": [
    { "id": "Counter1", "type": "myvendor.Counter", "options": { "scale": 2 } },
    { "id": "Lamp1",    "type": "myvendor.Lamp",    "options": { "maxBrightness": 128 } }
  ],
  "connections": [ "Counter1.result -> Lamp1.on" ]
}
```

Строка соединения читается прямо: «выход `result` устройства `Counter1`
передаёт данные во вход `on` устройства `Lamp1`». Полная картина с примером —
в [00-Overview](docs/00-Overview.md).

Этот репозиторий — ядро фреймворка, а не готовый сервис. В комплекте:
загрузка и запуск сервиса, базовый класс устройства (`Device`), порты,
действия и метрики, правила для опций и аргументов (`Rule`, `Validator`),
служебные модули — хранилище состояния, метрики, структура — ошибки с
кодами, и утилиты (импорт классов, воркеры, реактивность).
